# Chef-AI 🍳

A minimalist UI and frontend interface for smart kitchen organization and recipe discovery.

Before either of you starts coding: Always open your terminal and run git pull origin main to grab any new changes the other person pushed.

When you finish working: Save your files in VS Code and run these three commands:

git add .

git commit -m "brief description of your changes"

git push origin main

The Golden Rule: Never push code at the exact same time. If one of you is pushing or pulling, wait a minute for it to finish before the other person does.
